The Microsoft Learn Student Ambassador program, which I was part of from 2021 to 2024, came with an exam voucher. I spent it on the Data Analyst Associate exam, the skill closest to the supply chain work I was studying. Then Andrew Ng's machine learning course, a lot of YouTube, and the Azure Data Scientist Associate exam. After each one I wrote up how I had done it, and built a small Flask app that reads text out of images. Writing things down as I learned them became a habit I have kept.
