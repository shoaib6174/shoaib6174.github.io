I spent it on the Data Analyst Associate exam, the skill closest to the supply chain work I was studying. Then Andrew Ng's course, a lot of YouTube, and the Azure Data Scientist Associate exam. I wrote up each exam as I went, and a Flask app that reads text from images. Writing things up became a habit.
